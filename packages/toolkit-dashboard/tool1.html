Recommendations Tool

The Recommendation Tool is an interactive tool that allows farmers and advisors to gain insights on the available DATSs and request a recommendation of suitable DATSs, given:

  1. A farm/farmer archetype with sustainability preferences,
  2. Farm and farmer profile characteristics values,
  3. Natural language farm description and search text,
  4. DATS parameter filter values.

Farm/farmer archetypes

The user can select a farm/farmer archetype out of 5 predefined possibilities:

  • Family First: a legacy-driven farmer
  • Digital Autonomy: a seasoned, innovation-minded farmer
  • Cautiously Ardent: a prudent, cost-conscious innovator
  • Business Mentality: a performance-driven entrepreneur
  • Community Focused: community-oriented, values-driven farmer
Each archetype has its own set of predefined values for the 3 sustainability parameters: environmental, economic and social.

Farm and farmer profile characteristics values supported

The DATSs can be recommended based on a profile of some farm and farmer characteristics values that can be selected on the top side of the tool. The supported farm characteristics include:

  • Farm Type: the kind of farm (e.g., arable, dairy and fruit)
  • Country: the country where the farm is located
  • Language: the preferred language of the farmer
  • Technologies: the type of technologies the farmer can work with
  • Functionality: the functionality the farmer is looking for in a DATS
  • Benefits: the type of benefits the farmer wants to achieve with a DATS

Natural language descriptions

On top of the farm and farmer profile characteristics, the user can also give natural language descriptions of the farm and/or the required DATSs:

  • Farm description: a description of the farmer and the farm in free text
  • DATS description: a free text description of the required DATSs parameters.

DATS parameter filters supported

The DATSs can be filtered by selecting desired parameter values on the left side of the tool. The possible parameters to filter the DATSs include:

  • Agricultural Sector: the sector the DATS is targeting
  • Functionality: the relevant functionality of the DATS
  • Benefits: the benefits that can be reached by using the DATS
  • Digital Form: the digital form of the DATS
  • Language and Country : the supported language and targeted country of the DATS
  • Cost Structure: the cost structure of the DATS

Requesting a Recommendation

Once a farm/farmer archetype with sustainability preferences, a farm/farmer profile characteristics values, and/or a natural language farm description and search text has been entered, a recommendation for applicable DATSs can be requested by pushing the "Recommend DATSs" button. A columned list of recommended DATSs will be shown with a few parameters. When clicking on a DATS, more detailed information will be shown and if available also testcase information in which the DATS has been tested. In addition, in the left column a DATSs parameter filters bar is shown to further finetune the selection of DATSs.
